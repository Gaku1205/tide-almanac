# tide-almanac

釣り人・海辺の撮影者向けに、地点ごとの潮と日の出入りを読み解いて最適な時合いを予告し、有料では複数地点の比較と通知が使える潮汐暦サービス

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（会員登録して月額の有料プランで使う、ありきたりでない Web サービス（中身はおまかせ））から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
