# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は、開いてすぐ今日の潮が読める「道具」に見える。** 釣り具屋の潮見表や気象庁の潮位表のように、地点・日付・曲線・時刻が最初の画面に並び、宣伝の言葉や飾りの絵は置かない。夜の紺の面に、いまの潮の曲線が正確に刷られている。差し色は日の丸の朱だけで、「時合い（いちばん強い時間）」と主ボタンにしか使わない。

- 使う人：磯・堤防の釣り人、海辺（干潟・朝焼け）を撮る人。前の晩にスマホで「明日どこへ、何時に行くか」を決める
- 数字（時刻・潮位）は必ず等幅の書体で、表や曲線の中で一目で読める大きさにする。飾りより正確さ
- 有料の機能は、宣伝の節ではなく、道具の中の「鍵つきの行・欄」で見せる

## 無料と有料（画面の文言もこのとおり。値段は `src/lib/plan.ts` の `PRICE_YEN`）

- 無料：地点を1つ登録 / 今日と明日の潮汐曲線・満潮と干潮 / 日の出入り・月齢・潮名 / 時合いの予告（強さつき） / 撮影の「青い時間」（今日だけ）
- 有料プラン（月 480円）：無料のすべて ＋ **地点の比較**（12地点まで保存し、同じ日の時合いを強い順に並べる） / **時合いの通知**（前の晩21時・時合いの90分前） / **干潮の通知**（潮位が決めた高さを下回る朝） / **30日先まで**の暦と、撮影の「青い時間」×潮の高さ
- 比較表の行は `PLAN_ROWS`（`src/lib/plan.ts`）。足すときはここに足す
- 有料の機能は、画面でも書き込みでも、サーバーで `getViewer().pro` を確かめてから出す（`docs/billing.md`）。トップでは、無料の人には有料の範囲を「鍵つきの行・欄」（下の「部品」）で示し、中身は送らない

## 文字（`src/app/layout.tsx` で `next/font/google`）

- 本文・見出し：BIZ UDPGothic（400/700）`--font-body`。書体はこの1つだけ（明朝は使わない）。字間は 0〜0.02em（ボタン・ラベルも同じ。広げない）。`palt` を入れる
- 数字・時刻・英字のロゴ：IBM Plex Mono（400/500）`--font-num`。数字には必ず `.num` を付ける
- 大きさ：画面の見出し h1 24px（760px 以下 20px）／行間 1.4、節の見出し h2 20px、小見出し h3 17px、本文 16px・行間 1.8、補足 14px（それより小さくしない。図の目盛りだけ 12px）。見出しは 700
- 数字の大きさ：時刻・潮位は表と曲線の中で 15〜20px。値段も表の中で 20px。飾りの特大の数字は使わない
- 見出しは短い名詞だけ（「今日の暦」「明日以降」「地点の比較」「料金」「通知」「わたしの暦」「アカウント」）。「。」「、」で終わる見出し、`<br />` で2行に割った見出し、決め台詞は使わない。見出しを大きく見せて場面を作らない
- 見出しの上の小さいラベル（eyebrow）は置かない

## グリッドと余白

- 最大幅 1280px ＋ 左右の余白 `--gutter: clamp(20px, 5vw, 64px)`。中身は `.wrap` で包む
- 節の間は 48px（760px 以下 40px）。節の見出しと中身の間は 16px
- 幅の切り替え：1024px 以下で2段組みを1段に、760px 以下でスマホの並び

## 動き

- 潮汐曲線：読み込み時に左から右へ現れる（`clip-path`、1.6秒）
- いまの印：2.4秒ごとに輪が広がる
- ボタン：hover で色が濃くなり、「→」が 3px 右へ
- `prefers-reduced-motion: reduce` では、すべての動きを止める（曲線は最初から見える）

## 文言

- 実用の言い方で短く（釣り具屋の潮見表のように）。気取ったキャッチコピー・合言葉は使わない
- 潮の状態は「上げ三分」「下げ七分」「満潮」「干潮」、時合いの理由は「上げ潮 × 朝まずめ」「下げ潮 × 夕まずめ」「上げ潮の動き」、強さは「強」「並」「弱」
- 潮位は必ず「推算値」と書き添える（気圧・風・地形で変わる）。あわせて「潮位は気象庁の調和定数から推算」と出典を近くに書く（フッターと暦の注記）

## 避けること

- 朱を飾りに使う・朱の面を広く敷く・グラデーションの派手な背景
- 角の立った箱のカードを並べるだけの構成（罫線と余白で区切る）
- 数字を等幅以外で組む（等幅にそろえる）
- 写真の上に読みにくい文字を置く、14px より小さい本文
- 宣伝のページの型：左に大見出し＋本文＋ボタン2つ／右に角丸の写真（ヒーロー）、写真の上のガラス（ぼかし）の数字カード
- 気取ったキャッチコピー・合言葉・決め台詞、「。」「、」で終わる見出し、2行に割った見出し、大きな見出しで場面を作ること
- 明朝の見出し、字間を広げた組み、見出しの上の字間の広い小ラベル（eyebrow）
- 壱・弐・参のような飾りの番号を振った3列
- 背景の波線（`Waves`）・画面全体の縦罫
- 強さを丸で囲む・強さの数字を大きく見せる（帯の濃さと「強・並・弱」で見せる）
- 飾りの特大の数字（値段の「480」など）
