# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は「夜明け前の港で開く、一冊の潮汐暦」に見える。** 夜の紺の面と、古い暦の紙の面が章ごとに入れ替わり、その上に、いまの潮の曲線が正確に刷られている。差し色は日の丸の朱だけで、「時合い（いちばん強い時間）」と主ボタンにしか使わない。

- 使う人：磯・堤防の釣り人、海辺（干潟・朝焼け）を撮る人。前の晩にスマホで「明日どこへ、何時に行くか」を決める
- 数字（時刻・潮位・強さ）は必ず等幅の書体で、一目で読めること。飾りより正確さ

## 無料と有料（画面の文言もこのとおり。値段は `src/lib/plan.ts` の `PRICE_YEN`）

- 無料：地点を1つ登録 / 今日と明日の潮汐曲線・満潮と干潮 / 日の出入り・月齢・潮名 / 時合いの予告（強さつき） / 撮影の「青い時間」（今日だけ）
- 有料プラン（月 480円）：無料のすべて ＋ **地点の比較**（12地点まで保存し、同じ日の時合いを強い順に並べる） / **時合いの通知**（前の晩21時・時合いの90分前） / **干潮の通知**（潮位が決めた高さを下回る朝） / **30日先まで**の暦と、撮影の「青い時間」×潮の高さ
- 比較表の行は `PLAN_ROWS`（`src/lib/plan.ts`）。足すときはここに足す
- 有料の機能は、画面でも書き込みでも、サーバーで `getViewer().pro` を確かめてから出す（`docs/billing.md`）。トップの比較・通知・撮影の節は「見本」で、ログイン前でも見せてよい

## 文字（`src/app/layout.tsx` で `next/font/google`）

- 見出し：Shippori Mincho B1（600/700）`--font-head`。字間 0.04〜0.12em
- 本文：Zen Kaku Gothic New（400/500/700）`--font-body`。16px・行間 1.8〜2.0。`palt` を入れる
- 数字・時刻・英字のロゴ：IBM Plex Mono（400/500）`--font-num`。数字には必ず `.num` を付ける
- 大きさ：トップの h1 `clamp(44px, 7.4vw, 104px)`／行間 1.18、章の h2 `clamp(32px, 4.6vw, 60px)`／1.32、小見出し h3 `clamp(24px, 2.8vw, 34px)`、札の見出し 18〜22px、補足 13〜14px（それより小さくしない。図の目盛りだけ 12px）
- 見出しは `word-break: auto-phrase` と `text-wrap: balance`（1文字だけ次の行に落ちないように）。改行の位置を決めたい所は `<br />`
- 章の上の小さいラベル（eyebrow）：14px・字間 0.16em・補足の色

## グリッドと余白

- 最大幅 1280px ＋ 左右の余白 `--gutter: clamp(20px, 5vw, 64px)`。中身は `.wrap` で包む
- 12列・溝 24px。トップの見出しは 7列＋写真 5列、暦の読み方は 6列＋版画 5列（1列あけ）
- 章の上下の余白：PC 120〜136px、スマホ 96px
- 紙の章（暦の読み方）には、縦罫を4本 `rgba(28,36,48,.06)` で見せる（スマホでは消す）

## 部品

- **上の帯**（`SiteHeader`）：高さ 84px、背景なし（下の章に重ねる）。`tone="paper"` で墨の文字。しるし（朱の日の丸＋潮の線2本）＋「tide-almanac／潮汐暦」。右にリンクと、枠線の丸いログインボタン
- **ボタン**（`.btn`）：高さ 52px・角丸 999px・15px・字間 0.06em。主＝`.btnShu`（朱の面・白い字・右に「→」）、夜の上の副＝`.btnGhost`、紙の上の副＝`.btnInk`。スマホではボタンを横幅いっぱいに
- **潮汐曲線**（`TideChart`）：24時間を左から右へ。夜は暗い帯、薄明は薄い帯、時合いは朱の 16% の帯と上端 5px の朱の線。曲線は潮の青の線 2.25px ＋下へ消える塗り。満潮・干潮の札は「満／干」の丸＋時刻＋cm。いまの時刻は点線と脈打つ点。下に 0〜24 の目盛りと、日の出（朱の丸）・日の入り（朱の輪）。並べて比べるときは `domain` で潮位の物差しをそろえる
- **いまの潮の札**（トップの写真の上）：紺 72% ＋ぼかし、角丸 14px。「上げ三分」などは明朝、潮位は潮の青、次の時合いは朱の等幅
- **時合いの札**：枠線の角丸 14px。いちばん強い物だけ朱の枠と薄い朱の地。右に「強さ」と数字
- **結果の帯**（＝ 今日のいちばん強い時合い）：墨の面・角丸 20px・右に朱の丸（76px）で強さ
- **比較の表**：罫線だけの表（箱を作らない）。順位・地点（明朝）・曲線・いちばん強い時合い・強さの丸。1位だけ左から朱が薄くにじむ地と、朱の丸
- **料金**：無料と有料の2列を縦罫で分け、有料の上端に 4px の朱。値段は等幅 72px。比較表は有料の列だけ薄い朱の地
- **会員の画面**：ログインは左に写真・右に紙のフォーム（900px 以下は写真が上 300px）。入力欄は高さ 52px・角丸 12px・地 `#F7F2E7`・枠 `#B9AE98`、フォーカスで墨の枠＋朱の光。アカウントは紙の上に罫線の一覧と、紺の札の「有料プランにする」

- **わたしの暦の画面**（`/mine`。`src/components/mine.module.css`。新しい色は無く、上の表の物だけ）：夜の面（`--night`）に、箱を作らず罫線で区切る。上の帯は夜のまま、本文は上から 152px（スマホ 112px）下げる
  - 地点の登録欄（左 5列）：eyebrow「わたしの暦」・h2 の大きさの見出し「いつもの海を、登録する。」・説明。「登録 1 / 1 地点」は等幅 14px・`--haze`。選ぶ欄は入力欄と同じ（高さ 52px・角丸 12px・地 `#F7F2E7`・枠 `#B9AE98`、フォーカスで墨の枠＋朱の光）と、主ボタン「地点を追加 →」を横に並べる（スマホはボタンを横幅いっぱい）。上限に達したら選ぶ欄とボタンを隠す
  - 登録済み地点の一覧（右 7列）：上端に `--moon` の罫線、行の間は `--night-line`。1行＝連番（等幅 14px・`--haze`）・地点名（明朝 20px）・エリア（13px・`--haze`）・右に副ボタン形の「削除」（高さ 44px・枠 `--moon` 40%・角丸 999px）。空のときは「まだ地点がありません。」を `--haze` で
  - 断った理由・案内の文：罫線の角丸 12px の帯（枠 `--night-line`・文字 `#C9D2DB` 14px）。リンクは `--tide`
  - 無料の暦：登録した1地点の「今日」「明日」を縦に並べる。見出し（日付は等幅＋地点名）・潮名/満潮/干潮/日の出入りの並び・`TideChart`・時合いの札（トップの今日の暦と同じ。いちばん強い物だけ朱の枠）。最後に「※ 潮位は推算値。…」と、有料の案内（上に罫線、`.btnGhost` の「有料プランを見る」）
  - 有料の比較の表：見出しの上に朱の面の「有料」の札、h3 の大きさの見出し。表はトップの比較の節（`.board`）と同じ寸法・同じ色（1位だけ左から朱が薄くにじむ地、強さの丸は1位だけ `--shu-fill`）。登録が1地点だけのときは「地点を足すと、強い順に並べて比べられます。」を `--haze` で添える
  - 朱は、時合いのいちばん強い物・1位の丸・「地点を追加」の主ボタンだけ。1画面で2〜3か所に収める
- **アカウントの通知**（`/account`、紙の上。`member.module.css`。新しい色は無く、上の表の物だけ）：「あなたの暦」の一覧の下に、上端 1px `--sumi` の罫線で区切った節を置く（箱にしない）。見出し「通知」は明朝 24px。時合いの通知・干潮の通知は、24px のチェック（`accent-color` は `--tide-deep`）＋名前（500）＋補足（14px・`--sumi-soft`）の行で、行の下は `--paper-shade` の罫線。「干潮のしきい値（cm）」は会員の入力欄と同じ（高さ 52px・角丸 12px・地 `#F7F2E7`・枠 `#B9AE98`、フォーカスで墨の枠＋朱の光）で、数字は等幅。下の注記は 14px・`--sumi-soft`。保存は紙の上の副ボタン `.btnInk`「通知の設定を保存」（朱は使わない）。結果の文は、保存できたときは `--paper-shade` の帯、断ったときは赤みの帯（ログインの誤りと同じ）。無料には設定の代わりに `--paper-shade` の帯で「時合いと干潮の通知は有料プランの機能です。」と「有料プランを見る」のリンク
- **地点を探す**（トップ「今日の暦」の上、夜の章）：小見出しは明朝 22px。検索欄は高さ 52px・角丸 12px・地は透明・枠 `--haze`・文字 `--moon` 16px（フォーカスで `--moon` の枠＋朱の光）、横に副ボタン `.btnGhost`「探す」。ラベルは画面には出さず読み上げ用に付ける。件数は 14px・`--haze`。結果は罫線 `--night-line` だけの一覧で、地点名（明朝 18px・`--moon`）と地域（14px・`--haze`）を左右に振り分け、広い幅では複数列。選んでいる地点は地点名と下罫を `--tide` に。0件の文言は 15px・夜の上の本文色

- 暦の読み方：`02-fisherman-sunrise-sea.webp`（江戸の摺物）。角丸 4px と柔らかい影で「刷り物」として

## 動き

- 潮汐曲線：読み込み時に左から右へ現れる（`clip-path`、1.6秒）
- いまの印：2.4秒ごとに輪が広がる
- 背景の波線（`Waves`）：細い線が 38〜62秒で一周、横にゆっくり流れる
- ボタン：hover で色が濃くなり、「→」が 3px 右へ
- `prefers-reduced-motion: reduce` では、すべての動きを止める（曲線は最初から見える）

## 文言

- 合言葉：「潮と光が重なる刻を、前の晩に。」
- 潮の状態は「上げ三分」「下げ七分」「満潮」「干潮」、時合いの理由は「上げ潮 × 朝まずめ」「下げ潮 × 夕まずめ」「上げ潮の動き」
- 潮位は必ず「推算値」と書き添える（気圧・風・地形で変わる）

## 避けること

- 朱を飾りに使う・朱の面を広く敷く・グラデーションの派手な背景
- 角の立った箱のカードを並べるだけの構成（罫線と余白で区切る）
- 数字を明朝やゴシックで組む（等幅にそろえる）
- 写真の上に読みにくい文字を置く、14px より小さい本文
